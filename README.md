# Customer Order Manager

Android app for maintaining customer/order records.

## Fields
- Sr. No.
- Customer Name
- Customer Mobile Number
- Source of Person
- SOP Number
- Order Number
- Order Date
- Appointment Date
- Received Date
- Payment Status (Paid/Pending)

## Features
- Add records
- Edit records
- Delete records
- Search by customer, mobile, SOP or order number
- Automatic serial number
- Offline local storage using Android DataStore
- No internet permission required

## Build
Open this project in Android Studio (Ladybug or newer), allow Gradle to sync, then:
Build > Build App Bundle(s) / APK(s) > Build APK(s)

The debug APK will normally be in:
app/build/outputs/apk/debug/app-debug.apk
